# Code of conduct

Photonic has one rule for everyone who takes part, in its issues, pull requests and every other space the project runs: no illegal activity. There are no other restrictions.

## Reporting

Report a violation privately to the maintainer, [@robbie-vanderzee](https://github.com/robbie-vanderzee), at robert@vantle.org. The maintainer may remove anything that breaks the rule and block whoever is responsible.
